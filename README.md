# FarmQuest

A comprehensive farming quest application with gamified learning experiences for sustainable agriculture practices.

## Project Structure

```
farm-quest-ui-design/
├── frontend/          # Next.js React application
│   ├── app/          # Next.js 13+ app directory
│   ├── components/   # React components
│   ├── constants/    # Application constants
│   ├── hooks/        # Custom React hooks
│   ├── lib/          # Utility libraries
│   ├── public/       # Static assets
│   └── styles/       # CSS styles
├── backend/          # Backend API (to be implemented)
└── README.md         # This file
```

## Features

- 🌱 Interactive farming quests with gamification
- 🏆 XP and leveling system
- 🎯 Crop-specific learning modules with color-coded pills
- 📱 Mobile-responsive design
- 👨‍🌾 Farmer and admin authentication flows
- 📊 Progress tracking and achievements

## Getting Started

### Frontend Development

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Backend Development

```bash
cd backend
# Backend setup instructions will be added when implemented
```

## Tech Stack

### Frontend

- **Framework**: Next.js 16.0.3 with React
- **Styling**: Tailwind CSS with custom UI components
- **Icons**: Lucide React
- **Deployment**: Ready for Vercel/Netlify

### Backend (Planned)

- **API**: Node.js with Express.js
- **Database**: MongoDB/PostgreSQL
- **Authentication**: JWT tokens
- **File Storage**: Cloud storage for quest images
